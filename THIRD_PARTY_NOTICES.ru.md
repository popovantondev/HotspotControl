# Уведомления о сторонних компонентах

Автономная сборка для Windows содержит компоненты среды выполнения Microsoft .NET 10 и Windows Desktop. Для них продолжают действовать собственные условия. Копии лицензий и уведомлений из пакетов среды выполнения версии 10.0.11, использованных для этой сборки, находятся в `licenses/` и в ZIP-архиве:

- `licenses/dotnet-runtime-LICENSE.txt`
- `licenses/dotnet-runtime-THIRD-PARTY-NOTICES.txt`
- `licenses/windowsdesktop-runtime-LICENSE.txt`

Приложение использует сетевые API, поставляемые операционной системой Windows. В комплект не входят внешние файлы иллюстраций или сторонние библиотеки интерфейса. Значок Wi-Fi создаёт `tools/Build-Icon.ps1`; персонаж, ноутбук и сигнал нарисованы векторными элементами WPF в `src/HotspotControl.App/Assets/Scene.xaml`. Иллюстрации созданы для проекта по визуальным указаниям владельца. Если условия лицензии исходного изображения-образца неизвестны, их следует проверить перед публичной публикацией.

Перечисленные файлы среды выполнения относятся к конкретной версии сборки. Повторно проверяйте их при обновлении .NET или изменении упакованных зависимостей. См. [сведения о лицензии .NET](https://github.com/dotnet/core/blob/main/license-information.md).

# Hotspot Control — Дизайн-превью

Отдельная демонстрационная версия WPF на немецком, русском и английском языках. Все сетевые данные вымышлены. Превью не управляет настоящей точкой доступа и не изменяет автозапуск или пользовательские настройки. Изменения хранятся только в памяти. Основное приложение работает отдельно.

## Запуск

Потребуется .NET 10 SDK: `./Run-Preview.ps1`. Путь к портативной версии SDK можно передать через `-DotnetPath <путь к dotnet.exe>`.

Автономную версию x64 создаёт `./Publish-Preview.ps1`. Затем запустите `artifacts/HotspotControl-DesignPreview-win-x64/HotspotControl.Preview.exe`. Если язык не задан аргументом, при каждом запуске демо появляется окно выбора языка.

В отдельном демо-окне можно менять язык, сценарий и компактный режим. Нарисованная кнопка на ноутбуке переключает состояние симуляции. Окна устройств, настроек и ошибок используют тот же стиль. Закрытие главного окна завершает превью; настоящего системного трея у демо-версии нет.

## Проверка

`./Run-Preview.ps1 -ExportPath artifacts/preview-renders` проверяет переводы и демонстрационные сценарии, затем сохраняет рендеры WPF для всех языков и состояний. Эти изображения не являются снимками рабочего стола. Масштабирование Windows, управление с клавиатуры и системную рамку окна нужно дополнительно проверять непосредственно на экране.

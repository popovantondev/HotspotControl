# Hotspot Control 0.3.0

Die Windows-11-App für den mobilen Hotspot hat jetzt eine freigegebene kompakte Oberfläche auf Deutsch, Russisch und Englisch. Beim ersten Start wird die Sprache gewählt; in den Einstellungen kann sie für den nächsten Start geändert werden. Hauptfenster, Geräte, Einstellungen, Meldungen und Infobereich haben ein einheitliches Design. Außerdem verbessert diese Version die Wiederherstellung eines Einzelinstanz-Fensters, die Operationsserialisierung, Zeitüberschreitungen und die Übernahme der Einstellungen aus Version 0.2.0.

Das Release-ZIP ist eigenständig lauffähig auf Windows 11 24H2 oder neuer, x64. Alle Dateien entpacken und `HotspotControl.App.exe` starten; Installationsprogramm und Administratorrechte sind nicht erforderlich. Die Prüfsumme des Archivs steht in der Datei `.sha256`.

Automatische Prüfungen und WPF-Demodarstellungen verwenden fiktive Daten und schalten den echten Hotspot nicht um. Praktisch getestet wurde nur auf dem Computer des Eigentümers. Echtes Ein- und Ausschalten, Änderungen an Netzwerkname oder Passwort, Autostart nach der Windows-Anmeldung und andere Geräte- oder Richtlinienkombinationen gelten für diese Version als ungeprüft, sofern sie nicht separat dokumentiert sind. Windows-Richtlinien oder Hardware können Funktionen verhindern. Nach einem Zeitlimit kann Windows den Auftrag dennoch abschließen.

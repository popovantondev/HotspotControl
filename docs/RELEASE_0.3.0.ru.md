# Hotspot Control 0.3.0

У приложения для мобильной точки доступа Windows 11 появился утверждённый компактный интерфейс на немецком, русском и английском языках. При первом запуске выбирается язык; в настройках его можно изменить для следующего запуска. Главное окно, список устройств, настройки, сообщения и системный трей оформлены единообразно. В этой версии также улучшено восстановление единственного экземпляра, последовательное выполнение операций, сообщения о тайм-аутах и перенос настроек из версии 0.2.0.

ZIP-архив релиза автономно работает в Windows 11 24H2 и новее, x64. Распакуйте все файлы и запустите `HotspotControl.App.exe`; установщик и права администратора не нужны. Контрольная сумма архива находится в файле `.sha256`.

Автоматические проверки и демо-рендеры WPF используют вымышленные данные и не переключают настоящую точку доступа. Практические испытания проводились только на компьютере владельца. Настоящее включение и выключение, изменение имени сети или пароля, запуск приложения после входа в Windows, а также сочетания с другим оборудованием и политиками для этой версии не проверялись, если это отдельно не указано. Политики Windows или оборудование могут блокировать операции. Даже после тайм-аута Windows может завершить запрос.

На исходный код и бинарный файл распространяются [условия использования](../RIGHTS.ru.md). Для компонентов .NET в комплекте действуют также уведомления о [сторонних компонентах](../THIRD_PARTY_NOTICES.ru.md). Публичные изображения созданы из демонстрационных данных.

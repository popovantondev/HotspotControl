# Einheitliche Dialoge

Einstellungen und Geräte verwenden AppDialog als gemeinsamen Fensterrahmen:
Wi-Fi-Icon, Hintergrundverlauf, dunkler verschiebbarer Kopfbereich, gemeinsame
Schließen-Schaltfläche, feste Größe und deutsche Beschriftung. Neue Dialoge
sollen ebenfalls von AppDialog erben. Einstellungsfelder und Registerkarten
verwenden dunkle Farben mit hellem Text.

Release-Build ohne Warnungen und Fehler. Beide Dialoge geöffnet und über den
eigenen Schließen-Knopf geschlossen. Keine Netzwerkänderungen durchgeführt.

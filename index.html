Hotspot Control

Steuert den mobilen Windows-Hotspot und zeigt Geräte sowie Netzwerkeinstellungen.

Release · 0.3.0 Windows 11 24H2+ · x64
Herunterladen für WindowsQuellcode C# · .NET · WPFAnleitung ↗

Vor dem StartKompatibler WLAN-Adapter; Windows- oder Organisationsrichtlinien können Funktionen einschränken. .NET ist enthalten.

Was drin steckt

Installation, Funktionen, Datenschutz, Prüfung.

Installation

Archiv prüfen, entpacken, starten.

PS> Get-FileHash .\HotspotControl-0.3.0-win-x64.zip -Algorithm SHA256
PS> Get-Content .\HotspotControl-0.3.0-win-x64.zip.sha256
Beide Werte müssen übereinstimmen.
PS> Expand-Archive .\HotspotControl-0.3.0-win-x64.zip -DestinationPath .\HotspotControl
PS> .\HotspotControl\HotspotControl-0.3.0-win-x64\HotspotControl.App.exe

Läuft lokal

Keine Cloud, keine Telemetrie. Einstellungen liegen in %LOCALAPPDATA%\HotspotControl; Passwörter speichert die App nicht.

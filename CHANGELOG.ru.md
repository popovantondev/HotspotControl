# История изменений

## 0.3.0 — 2026-09-27

- Единый интерфейс WPF для главного окна, устройств, настроек и сообщений.
- Немецкий, русский и английский языки; выбор языка при первом запуске.
- Состояния раздачи, ошибки и тексты системного трея на выбранном языке.
- Надёжнее восстановление единственного экземпляра и ограниченные по времени операции Windows.
- Сохранение настройки автовключения из версии 0.2.0 при обновлении.
- Демо-превью на вымышленных данных и документация продукта на трёх языках.

## 0.2.0 — 2026-09-09

- Автономный пакет для Windows x64 со средой .NET.
- Запускается только один экземпляр; повторный запуск восстанавливает существующее окно.
- Последовательная обработка запросов Windows и ограниченное время ожидания.
- Ограниченное число повторов, пока интернет-соединение ещё не готово.
- Восстановление окна не запускает автовключение повторно.
- Спокойное фоновое обновление и сохраняющиеся сообщения об ошибках.
- Параметры автозапуска корректно сохраняются при управлении клавиатурой и средствами автоматизации.
- Практическая проверка включения/выключения и сохранения конфигурации без изменений.
- 36 проверок поведения, проверка интерфейса, документация на немецком и локальная история Git.

## Прототип

Состояние точки доступа, включение и выключение, настройки, список устройств, фирменный стиль WPF, многоуровневый значок Wi-Fi, скруглённые окна, автозапуск и системный трей.

Hotspot Control

Control Windows Mobile Hotspot and view devices and network settings.

Download for WindowsSource code C# · .NET · WPFUser guide ↗

Before you startCompatible Wi-Fi adapter; Windows or organization policy may restrict operations. .NET is bundled.

What's inside

Installation, features, privacy, checks.

Installation

Verify, extract, start.

PS> Get-FileHash .\HotspotControl-0.3.0-win-x64.zip -Algorithm SHA256
PS> Get-Content .\HotspotControl-0.3.0-win-x64.zip.sha256
Both values must match.
PS> Expand-Archive .\HotspotControl-0.3.0-win-x64.zip -DestinationPath .\HotspotControl
PS> .\HotspotControl\HotspotControl-0.3.0-win-x64\HotspotControl.App.exe

Runs locally

No cloud, no telemetry. Settings stay in %LOCALAPPDATA%\HotspotControl; the app does not store passwords.
